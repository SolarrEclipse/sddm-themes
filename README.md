# SDDM Themes for my Rice
> This Repo is a collection of my sddm configs / rices

### March Theme
This Theme is made for my own dotfiles called march.
Currently the only version in this repo, so no naming yet.

It consists of a glass Panel in the center of the background with following content:
- Clock, Top Center
- Circle Avatar Cutout centered
- Username
- Password Input Field
- Reboot and Shutdown Buttons

On the top left of the whole screen is a session switcher for selecting:
- Hyprland, Sway or other compositors
- KDE Plasma, Gnome or other Desktop Environments

Just the average switcher.
